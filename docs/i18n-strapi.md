# Контент на разных языках (Strapi)

Сайт уже запрашивает контент по выбранному языку (`/ru`, `/be`, `/en`). Чтобы на сайте отображался разный текст, нужно в Strapi завести локали и заполнить контент для каждой.

## 1. Добавить локали в Strapi

1. Откройте **Админку Strapi** (например `http://localhost:1337/admin`).
2. Перейдите: **Settings (Настройки)** → **Internationalization**.
3. Убедитесь, что есть локали с кодами **ru**, **be**, **en** (как на сайте).
   - Если какой-то нет — нажмите **Add new locale** и добавьте:
     - **ru** — Русский  
     - **be** — Белорусский  
     - **en** — English  
   - Одну из них можно пометить как **Default locale** (например ru).

## 2. Включена ли локализация у типов контента

Для типов **Страница**, **News (статьи)**, **Меню**, **Global Settings**, **Event**, **Администрация**, **Специальности** в схеме включена локализация (`i18n.localized: true`). После изменения схемы **перезапустите бэкенд** (например `npm run dev:cms` в корне проекта).

## 3. Как заполнять контент по языкам

### Важно: переключение локали в админке

В Strapi при смене локали в выпадающем списке (справа сверху) форма **не перезагружает данные** с сервера — на экране остаются поля предыдущей локали. В базе при этом хранятся **разные** данные для каждой локали, на сайте они отображаются правильно.

**Что делать:** после смены локали (RU → Белорусский → English) **обновите страницу (F5)**. Тогда подтянутся данные выбранной локали, и вы будете редактировать нужный вариант.

Удобный вариант: открыть одну и ту же запись (например, страницу «Администрация») в **трёх вкладках** браузера — в одной вкладке RU, в другой BE, в третьей EN — и править каждую локаль в своей вкладке.

### Коллекции (Страницы, Новости, События)

1. **Content Manager** → нужный тип (например **News**).
2. Откройте запись (или создайте новую).
3. Справа вверху выберите **локаль** (RU / Белорусский / English). После смены локали **обновите страницу (F5)**.
4. Заполните поля на выбранном языке и сохраните.
5. Чтобы добавить ту же запись на другом языке:
   - Выберите другую локаль в переключателе, обновите страницу (F5).
   - Либо нажмите **"Fill in from another locale"**, отредактируйте перевод и сохраните.

Повторите для всех нужных страниц, новостей и событий по каждой локали (ru, be, en).

### Одиночные типы (Меню, Global Settings, Администрация, Специальности)

1. **Content Manager** → тип (например **Меню** или **Global Settings**).
2. Вверху справа переключите **локаль** (RU / be / en). После смены **обновите страницу (F5)**.
3. Для каждой локали заполните свои значения (пункты меню, контакты и т.д.) и сохраните.

## 4. Проверка на сайте

- Откройте сайт: `/ru` — русский, `/be` — белорусский, `/en` — английский.
- Переключатель языков в шапке (RU | BY | EN) ведёт на ту же страницу с другой локалью.
- Если для выбранной локали запись не заполнена, Strapi может вернуть пустой ответ или fallback на другую локаль (зависит от настроек). Поэтому для видимого отличия нужно заполнить контент минимум для двух локалей (например ru и en).

## Кратко

| Где | Что сделать |
|-----|-------------|
| **Settings → Internationalization** | Добавить локали **ru**, **be**, **en** |
| **Content Manager** для каждого типа | Выбирать локаль (RU / be / en) и заполнять/переводить контент |
| После смены схем (i18n) | Перезапустить бэкенд Strapi |

После этого контент на сайте будет меняться в зависимости от выбранного языка.
